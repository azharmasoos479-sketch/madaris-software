# Madaris Software — Features (مدارس سافٹ ویئر)

1. **طلبہ** — full record: guardian, phone, previous madrasa, class/stream, roll, admission, active/left, per-student monthly fee; search/filter/CSV/print.
2. **اساتذہ و عملہ** — roles (استادِ حفظ، ناظرہ، درس نظامی، ناظم، سامع، محاسب، خدمت گار), subjects, salaries.
3. **حاضری** — daily + hourly (گھنٹہ وار), حاضر/غیر حاضر/رخصت, per class & date, absence counts.
4. **حفظ و ناظرہ** — sabaq log: سبق/سبقی/منزل/ناظرہ/قاعدہ, پارہ, سورت, آیات, صفحات, غلطیاں, اٹکان, سامع (teacher or student), کیفیت; filter by student/type/teacher; every entry stamped with the entering user's name (own records).
5. **فیس** — monthly charge generation, class-wise fees, collection with receipt numbers, partial payments, student ledger, printable receipt, defaulter list with one-tap WhatsApp reminders to guardians (wa.me links).
6. **امتحانات** — per-class book/subject selection with totals, marks entry, auto total/percentage/grade (ممتاز 80%+، جید جداً 70%+، جید 60%+، مقبول 50%+، راسب <50%), class positions, printable result card.
7. **مالیات** — income/expense ledger with categories, cash/bank accounts, auto receipt numbering, balances, monthly salary summary, CSV export.
8. **اعلانات و الرٹس** — announcements (by user), today's absent students list with one-tap WhatsApp alert to each guardian.
9. **صارفین و رولز** — admin creates users (منتظم/استاد/محاسب/عملہ) with own email+password; personal records tracked per user.
10. **ترتیبات** — madrasa profile, classes/streams management, JSON backup & restore, demo reset.
11. **PWA** — installable on Android (manifest + service worker + offline cache), ready for APK packaging.
